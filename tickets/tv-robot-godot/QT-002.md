# QT-002 — Implement the TV robot, room, grapple and recoverable ragdoll

Status: confirmed
Owner: Primary implementer
Dependencies: QT-001 supplies geometry/input and shared integration contract.

## Outcome

Recreate the active player experience, not just movement.

## Scope and approach

Implement main scene with fixed logical room, authored TV-faced articulated robot, A/D/arrows walking, Space jump, S crouch, both Shift keys run, pointer punch, right-click grapple/release, R release, restart and basic touch movement. Native Godot collision prevents room/platform tunneling. Grapple handles static and creature targets with conserved release momentum. Hard impacts produce loose articulated ragdoll, and input restores upright control. No enabled portal gun/glitch/frog expansion.

Shared context: [initiative index](INDEX.md), [module contract](../../sources/tv-robot-godot/MODULE-CONTRACT.md), existing [TV Robot source](../../games/tv-robot/index.html).
